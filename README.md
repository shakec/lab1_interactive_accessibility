### 2. How do ARIA attributes improve the experience for users relying on assistive technologies?
<p> ARIA attributes improve the user expereince of those relying on assistive tech by providing them alternative ways to interact with the web content they are viewing. Some technologies allow tabbing through the important content/links on a page for those have trouble with hand dexterity or other hinderances; and for those with visual roadblocks, there are contrast features to enhance or make items that aren't easily seen to be made visible for their color spectrum, or screen readers to guide navigation.

### 3. What tools did you use to check color contrast, and how did they help?
<p> The tool I use to check the color contrast is [Stark](https://www.getstark.co) for one it's out of habit, I've learned to trust it as a plugin for Sketch and Figma; the developers made meeting WCAG contrast requirements easy especially with their color picker and side-by-side comparison. Then I found their browser extension which still has the level of reliability and ease-of-use that I trust. I did try WebAIM but I'm expecting more from it than I think it can offer.
